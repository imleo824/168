老板评审单（不看代码版）
========================

每次上线前都使用本模板。
技术同学负责填写，老板只做决策。

1) 这次做了什么
===============
- 用业务语言写 1-3 句话。

2) 用户会看到什么变化
=====================
- 哪些页面/流程变化了。
- 变化前后有什么差异。

3) 需求是否达标
===============
- [ ] 达成需求目标
- [ ] 达成验收标准
- [ ] 优化场景下行为无变化（仅优化）
- [ ] 数据/流程改动可接受（仅新功能）

4) 风险与影响
=============
- 影响范围：
- 对转化/留存的预期影响：
- 主要风险：
- 缓解方案：

5) 上线与回滚
=============
- 计划上线时间：
- 回滚触发条件：
- 回滚步骤已验证： [ ] 是  [ ] 否
- 回滚影响：

6) 老板决策（一句话）
=====================
- ``通过上线``
- ``退回修改：原因...``
